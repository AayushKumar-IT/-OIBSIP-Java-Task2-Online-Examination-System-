# Online Examination System

A Java Swing-based online examination system with:
- login and profile management
- MCQ exam flow
- timer and scoring
- result summary

## Project structure

- src/com/exam/model
- src/com/exam/data
- src/com/exam/service
- src/com/exam/ui
- src/com/exam/util

## Run

```bash
javac -d out $(find src -name "*.java")
java -cp out com.exam.Main
```
